# LelekaThoughts

Соціальна мережа для креаторів: короткі пости, авторські ланцюжки та сторіс із постійними серіями. Адаптивний інтерфейс із бічною навігацією, світлою й темною темами та українською й англійською мовами.

## Локальний запуск

Потрібен Node.js 22.13 або новіший.

```sh
cd app
npm ci
npm run dev
```

Відкрийте адресу, яку надрукує dev-сервер (за замовчуванням `http://localhost:5173`). Клієнт підключений до окремого Supabase-проєкту LelekaThoughts; це спільна віддалена база, а не локальний емулятор. Демонстраційні профілі позначені в інтерфейсі.

## Що включено

- Стрічки «Для тебе» та «Підписки», профілі й пошук.
- Пости з фото, авторські ланцюжки, коментарі, вподобайки, репости та цитування.
- Сторіс із фото/відео, іменовані серії та прив’язка до ланцюжків.
- Підписки, приватні збереження й чернетки, внутрішні сповіщення.
- Особисті чати й повідомлення-запити, блокування, скарги та інтерфейс модератора.
- PWA manifest, іконки та online-first service worker.
- SQL-схема з правилами доступу та серверні функції Supabase.

## Статус і налаштування

Приватні публікації, місячні підписки з автопродовженням і разові покупки підготовлені окремою міграцією. Порядок підключення, обмеження й перевірки: [MONETIZATION-SETUP.md](app/docs/MONETIZATION-SETUP.md). До погодження production-міграції та підключення merchant-акаунтів реальні платежі вимкнені.

Production: [lelekathoughts.vercel.app](https://lelekathoughts.vercel.app).

### Деплой на Vercel

Коренева директорія застосунку для Vercel — `app`. Конфігурація `app/vercel.json` використовує нативну Next.js-збірку `npm run build:vercel`; звичайний `npm run build` зберігає збірку Vinext для Sites.

```sh
cd app
npx vercel deploy --project lelekathoughts --scope sekhvolodymyrs-projects --prod
```

Виконуйте локальну Next.js-збірку після зупинки dev-сервера Vinext: обидва інструменти генерують типи в `.next`. Для Vercel збірка відбувається в окремому середовищі. Необхідні адреси OAuth/email описані в інструкції підключення нижче.

Це поточний MVP, а не підтверджений завершений публічний запуск. Google OAuth, власний SMTP-відправник, адреси повернення та шаблони email потребують налаштувань власника. Перший адміністратор призначається явно. Частина наскрізних перевірок ще потребує завершення.

- [Погоджений PRD](PRD.md)
- [Підключення Google та email](app/docs/AUTH-SETUP.md)
- [Стан реалізації та відомі обмеження](app/docs/IMPLEMENTATION.md)
- [Дизайн-система](app/design/SYSTEM.md)

Клієнтські Supabase publishable/anon keys є відкритими за призначенням; права доступу перевіряються в базі та серверних функціях. Приватні ключі й локальні `.env` не мають потрапляти до Git.

## Перевірки

```sh
cd app
npx tsc --noEmit
npm run build
```

SQL у `app/supabase/schema.sql` та `maintenance.sql` зберігає джерело схеми вже створеного проєкту. Не запускайте його повторно поверх наявної бази; порядок відтворення описано в документації реалізації.
