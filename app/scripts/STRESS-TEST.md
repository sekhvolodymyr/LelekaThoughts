# Навантаження та ізоляція даних

`stress-system.mjs` запускає 100 API-клієнтів із реальними Supabase-сесіями. Використовується стандартний публічний ключ, без service-role у клієнтах. Перший прогін із швидким входом і основний прогін зберігаються окремо.

```powershell
node app/scripts/stress-system.mjs .tooling/stress-credentials.json artifacts/stress-run
```

Маніфест — приватний JSON із `runId`, `password`, `users` (100 об’єктів `id`, `email`), `url`, `publicKey`, `site`. Run ID має починатися з `ltstress_`; адреси — `<runId>_001@example.invalid` … `_100@example.invalid`. Створення підтверджених тестових акаунтів виконує оператор у власному проєкті. Не використовуйте особисті акаунти. Секрети, сесії та маніфест не комітити.

Вхід готується поступово з урахуванням rate limit, після чого фази запускають одночасно 100 користувачів. Запити бізнес-дій автоматично не повторюються: timeout може приховувати вже виконану операцію. Негативні перевірки відрізняють очікувану відмову 4xx від timeout/429/5xx. Кожен запит має час, назву операції, індекс користувача, HTTP-статус і тривалість у `requests.jsonl`; токени й паролі не журналюються.

Перевіряються пости, ланцюжки, коментарі, вподобайки, підписки, репости, збереження, чернетки, маленькі PNG, сторіс/серії, дедуплікація переглядів, запити/прийняття чатів, приватні читання, власність, адмінправа, блокування й паралельна нумерація частин. Тестові мутації адресують лише ID із власного маніфесту. Публічні тестові пости та сторіс тимчасово видимі іншим відвідувачам; перевірки переглядів рахують лише глядачів із маніфесту.

Після прогону клієнт пробує видалити власні медіа й закрити сесії. `stress-recover.mjs` дозволяє послідовно повторити очищення конкретних десяти PNG після зупинки навантаження. Фізичне видалення акаунтів і рядків із точним маркером прогону виконує оператор, після чого потрібна перевірка нульових залишків. Збережіть `stress-state.json` до завершення очищення. Не використовуйте широкі шаблони видалення.

Обмеження: це коротке API-навантаження, без симуляції рендерингу та Realtime-підписок 100 браузерів. Не перевіряє доставку email, Google consent, Android-пристрої, реальну тривалість відео або повне вичерпання квот. Не вважайте успішні API-відповіді сертифікатом безпеки чи оцінкою максимальної місткості.

`stress-report.mjs` формує підсумковий український `.log` із збережених вимірювань та окремого контексту перевірки. Початкові результати не переписуються.
